# power-pi-report-sales-project
This project presents a sales performance analysis for the first quarter of 2019, providing insights into supermarket transactions across different cities, product lines, and customer demographics. The dashboard includes key visualizations, such as total sales by branch, gross income per product category, and revenue trends over time.
# Supermarket Sales Analysis Dashboard

## **Overview**
This project visualizes supermarket sales data for **Q1 2019**, helping businesses and analysts track revenue trends, customer purchasing behavior, and product performance.

### **Key Insights:**
- **Gross income per product line** (Food, Electronics, Fashion, etc.)
- **Total sales by city and branch** (Naypyitaw, Yangon, Mandalay)
- **Revenue trends across months** (January–October)
- **Customer gender distribution**
- **Cost, total revenue, and net profit analysis**

## **Technologies Used**
- **Power BI** for dashboard creation
- **Excel** for initial data formatting
- **SQL** for data extraction and manipulation

## **Usage**
This dashboard assists retailers in making **data-driven decisions** by highlighting revenue-generating product categories, seasonal trends, and customer behavior insights.

## **Installation**
1. **Download the Power BI file** from the repository.
2. **Open the dashboard** in Power BI.
3. **Analyze sales trends** using interactive filters and visualizations.
